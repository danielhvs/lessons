Bhaskara's formula

Find exactly where a parabola crosses the x axis: the x that makes ax² + bx + c equal 0.

1The problem

Which x makes x² − 2x − 3 equal 0? An equation like this, where the highest power of x is x², is a quadratic: ax² + bx + c = 0 with a not 0. Each x that solves it is a root.

Draw y = x² − 2x − 3 and you get a U-shaped curve, a parabola. The roots are where it touches the floor, y = 0. Here you can see two spots, but reading them off a drawing is a guess, and trying values by hand only works when the roots are whole numbers:

x = 0  →  0 − 0 − 3  = −3
x = 1  →  1 − 2 − 3  = −4
x = 2  →  4 − 4 − 3  = −3
x = 3  →  9 − 6 − 3  = 0

With a root like 1.37 guessing finds nothing. Bhaskara's formula (the name used in Brazil for the quadratic formula, after the Indian mathematician Bhaskara II) gives every root exactly, for any a, b, c.

2The smallest example: x² − 2x − 3 = 0

Three moves. First read the coefficients a, b, c: the numbers in front of x², in front of x, and alone. The minus signs belong to the numbers.

Then compute Δ (delta, the discriminant): Δ = b² − 4ac. It is the number that goes under the square root, and its sign says how many roots there are.

Last, plug into x = (−b ± √Δ) / 2a. The ± (plus or minus) means: do it once with + and once with −. Each gives one root.

a·x² + b·x + c = 0
1·x² − 2·x − 3 = 0     →  a = 1, b = −2, c = −3

Δ = b² − 4·a·c
Δ = (−2)² − 4·1·(−3)
Δ = 4 + 12 = 16

x = (−b ± √Δ) / (2·a)
x = (−(−2) ± √16) / (2·1)
x = (2 ± 4) / 2

x₁ = (2 + 4) / 2 = 6 / 2  = 3
x₂ = (2 − 4) / 2 = −2 / 2 = −1

Check by plugging back in: 3² − 2·3 − 3 = 9 − 6 − 3 = 0 and (−1)² − 2·(−1) − 3 = 1 + 2 − 3 = 0.

3What Δ tells you

Keep a = 1 and b = −2 and change only c. Then Δ = (−2)² − 4·1·c = 4 − 4c, and c only slides the curve up and down. As it rises, the two roots walk toward each other, merge, then disappear.

Why no root when Δ < 0: the formula needs √Δ, and no real number (a number on the number line) times itself gives a negative, so √(−8) has no real answer. Stop at Δ: the sign decides before you do the rest.

4A new example: x² − 5x + 6 = 0

a = 1, b = −5, c = 6

Δ = (−5)² − 4·1·6 = 25 − 24 = 1
x = (5 ± √1) / 2 = (5 ± 1) / 2

x₁ = 6 / 2 = 3
x₂ = 4 / 2 = 2

check: 3² − 5·3 + 6 = 9 − 15 + 6 = 0
       2² − 5·2 + 6 = 4 − 10 + 6 = 0

5When a is not 1: −2x² + 4x + 6 = 0

With a negative a the parabola opens downward. The formula does not change; watch the signs. −4·(−2)·6 is +48, and the 2a below is −4.

a = −2, b = 4, c = 6

Δ = 4² − 4·(−2)·6 = 16 + 48 = 64
x = (−4 ± √64) / (2·(−2)) = (−4 ± 8) / −4

x₁ = 4 / −4   = −1
x₂ = −12 / −4 = 3

Same roots as x² − 2x − 3: this equation is that one multiplied by −2, and multiplying both sides of "= 0" by a number does not move the roots.

6Why the formula works

Take a = 1 (divide everything by a first). Draw x² as a square of side x, and bx as a rectangle x by b cut into two strips of width b/2. Put one strip on the right and one below: the corner is missing. Adding that corner, (b/2)², to both sides is completing the square.

x² + bx + c = 0
x² + bx = −c
x² + bx + (b/2)² = (b/2)² − c
(x + b/2)² = (b² − 4c) / 4     ← there is Δ
(x + b/2)² = Δ / 4
x + b/2 = ± √Δ / 2
x = (−b ± √Δ) / 2

The ± appears because both +√ and −√ square back to the same number. With any a the same steps give the 2a below: x = (−b ± √Δ) / 2a, with Δ = b² − 4ac.

7In code

import math

def bhaskara(a, b, c):
    delta = b*b - 4*a*c
    if delta < 0:
        return []
    r = math.sqrt(delta)
    return sorted({(-b + r) / (2*a), (-b - r) / (2*a)})

print(bhaskara(1, -2, -3))
print(bhaskara(1, -2, 1))
print(bhaskara(1, -2, 3))
print(bhaskara(-2, 4, 6))
print(bhaskara(1, -5, 6))

The five equations of this page. { } is a set: with Δ = 0 both sums give 1.0 and the set keeps one copy. Δ < 0 returns an empty list, no root.

8Common mistakes

Dropping the sign of b. In x² − 2x − 3, b is −2, not 2. With b = 2 you get the roots 1 and −3, the mirror image. Fix: write the equation as 1·x² + (−2)·x + (−3) = 0 first.

Squaring without parentheses. −2² is −4 (square first, then the minus); (−2)² is 4. Python agrees: print(-2**2, (-2)**2) prints -4 4. Fix: always put b in parentheses before squaring, so b² is never negative.

Losing the minus in −4ac. With c = −3, −4·1·(−3) is +12, so Δ = 4 + 12 = 16, not 4 − 12. Fix: multiply the three signs out before adding.

Dividing only √Δ by 2a. −b ± √Δ / 2a is a different number. Fix: the whole top, −b ± √Δ, goes over 2a.

Taking a square root of a negative Δ. It is not a calculation error: Δ < 0 means no real root, and the answer is "none". Fix: check the sign of Δ before going on.

Summary

  1. Write it as ax² + bx + c = 0 and read a, b, c with their signs.
  2. Δ = b² − 4ac: Δ > 0 two roots, Δ = 0 one root, Δ < 0 no real root.
  3. x = (−b ± √Δ) / 2a: once with +, once with −.
  4. The roots are where the parabola crosses y = 0; plug them back in to check.
  5. The formula is completing the square: add (b/2)² to make x² + bx a perfect square.
