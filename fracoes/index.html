Frações

Como escrever, comparar, somar, multiplicar e dividir pedaços de um inteiro.

1O problema

Uma barra de chocolate para 3 pessoas: cada uma fica com quanto? Não é 1 barra nem 0 barra. Os números inteiros (0, 1, 2, 3...) não têm resposta para isso. A fração é o número que conta pedaços de um inteiro cortado em partes iguais: cada pessoa fica com 1/3 da barra.

2O menor exemplo: 3/4

Corte uma barra em 4 pedaços iguais e pegue 3. Isso é 3/4 (três quartos).

O denominador é o número de baixo: em quantos pedaços iguais o inteiro foi cortado (4). O numerador é o número de cima: quantos pedaços você pegou (3). Cada pedaço vale 1/4, e sobra 1 pedaço.

3Mesma quantidade, nomes diferentes

Pinte metade da barra: 1/2. Corte cada pedaço em 2: agora são 4 pedaços e 2 pintados, 2/4. Corte cada um em 3: 3/6. A parte pintada não mudou de tamanho.

Essas são frações equivalentes: nomes diferentes para a mesma quantidade. A regra: multiplicar o numerador e o denominador pelo mesmo número.

1/2 = (1×2)/(2×2) = 2/4
1/2 = (1×3)/(2×3) = 3/6
python3 -c "from fractions import Fraction as F; print(F(1, 2) == F(2, 4) == F(3, 6))" True

4Simplificar

Simplificar é o caminho de volta: dividir em cima e embaixo pelo mesmo número, até chegar aos menores números que dão a mesma quantidade.

Em 6/8, o maior número que divide 6 e 8 é 2. Esse número se chama MDC (máximo divisor comum). Dividindo os dois por 2:

6/8 = (6÷2)/(8÷2) = 3/4
python3 -c "from fractions import Fraction as F; print(F(6, 8))" 3/4

5Comparar: qual é maior?

2/3 ou 3/5? Os pedaços têm tamanhos diferentes (terços e quintos), então comparar 2 com 3 não diz nada.

Corte as duas barras no mesmo tamanho de pedaço. 15 serve, porque 3 × 5 = 15:

2/3 = (2×5)/(3×5) = 10/15
3/5 = (3×3)/(5×3) = 9/15

Agora é só contar: 10 é maior que 9, então 2/3 é maior, por 1/15. Esse fundo comum (15) se chama denominador comum.

python3 -c "from fractions import Fraction as F; print(F(2, 3) > F(3, 5), F(2, 3) - F(3, 5))" True 1/15

6Somar

Com o mesmo denominador, some os numeradores e mantenha o denominador, porque o tamanho do pedaço não mudou:

1/5 + 2/5 = 3/5

Com denominadores diferentes, primeiro reescreva as duas frações com um denominador comum. O menor deles é o MMC (mínimo múltiplo comum): o menor número que os dois denominadores dividem. O MMC de 2 e 3 é 6:

1/2 + 1/3
= 3/6 + 2/6
= 5/6
python3 -c "from fractions import Fraction as F; print(F(1, 2) + F(1, 3))" 5/6

7Multiplicar: fração de uma fração

2/3 × 3/4 quer dizer "2/3 de 3/4". Pinte 3 de 4 colunas (3/4) e, dentro delas, pegue 2 de 3 linhas (2/3). As células roxas estão nas duas partes.

Regra: multiplique em cima com em cima e embaixo com embaixo.

2/3 × 3/4 = (2×3)/(3×4) = 6/12 = 1/2
python3 -c "from fractions import Fraction as F; print(F(2, 3) * F(3, 4))" 1/2

8Dividir: quantas cabem?

3 ÷ 1/2 pergunta: quantas metades cabem em 3 inteiros? Cada inteiro tem 2 metades, então são 6.

Atalho: dividir por uma fração é multiplicar pelo inverso dela, a fração de cabeça para baixo. O inverso de 1/2 é 2/1:

3 ÷ 1/2 = 3 × 2/1 = 6
python3 -c "from fractions import Fraction as F; print(3 / F(1, 2))" 6

9Mais que um inteiro

Em 7/4 o numerador é maior que o denominador: é mais que um inteiro. Isso é uma fração imprópria.

4 quartos enchem uma barra e sobram 3: 7/4 = 1 inteiro e 3/4. Escrito como número misto: 1 3/4, que em decimal é 1,75.

python3 -c "from fractions import Fraction as F; print(F(7, 4), float(F(7, 4)))" 7/4 1.75

10Erros comuns

Somar em cima e embaixo: 1/2 + 1/3 = 2/5 está errado. 2/5 = 0,4 é menor que 1/2 = 0,5, e somar não pode diminuir. Correção: denominador comum primeiro, 3/6 + 2/6 = 5/6.

python3 -c "from fractions import Fraction as F; print(F(1, 2) + F(1, 3) == F(2, 5), float(F(2, 5)))" False 0.4

Achar que denominador maior é fração maior: 1/4 é menor que 1/3. Cortar em mais pedaços deixa cada pedaço menor.

Mudar só um dos números: 1/2 → 2/2 não é equivalente (2/2 é um inteiro). Para ter a mesma quantidade, multiplique ou divida em cima e embaixo pelo mesmo número.

Inverter a fração errada na divisão: em 3 ÷ 1/2, quem vira de cabeça para baixo é a de depois do sinal (1/2 → 2/1), não o 3.

Resumo

  1. Denominador (embaixo): em quantos pedaços iguais o inteiro foi cortado. Numerador (em cima): quantos você pegou.
  2. Multiplicar ou dividir em cima e embaixo pelo mesmo número dá a mesma quantidade (equivalentes, simplificar).
  3. Para comparar, somar ou subtrair, primeiro deixe os pedaços do mesmo tamanho (denominador comum, o MMC).
  4. Multiplicar: em cima × em cima, embaixo × embaixo. Dividir: multiplique pelo inverso.
  5. Numerador maior que o denominador é mais que um inteiro: 7/4 = 1 3/4.
